# 故障排查

## 启动或内核失败

完整解压发布包，确认架构正确。安装/修复 Microsoft 官方 WebView2 Evergreen Runtime 后重试。数据目录必须可写；不要删除现有保险箱来“修复启动”。更新时先退出旧进程，否则单实例机制只会把旧窗口唤醒。

SmartScreen 与代码签名属于发布信任问题，不能用关闭保护或改启动方式代替。预览版未签名，正式签名分发尚待完成。

## 网页慢或显示验证页面

先区分网站正文、后台图片/统计请求以及网站安全验证。应用在正文就绪时结束顶部进度，但剩余资源可能仍在下载。后台页面休眠是 WebView2 尽力执行的请求，音频、下载和全屏标签受到保护，不能保证全部网页接受休眠。

刷新当前页；需要绕过缓存时使用 Ctrl+Shift+R。检查系统网络和 WebView2 版本。不要在 Issue 中上传 Cookie、完整网络日志或私密 URL。第三方站点可以拒绝嵌入式浏览器，应用无法保证验证通过。外部 Edge 入口有独立会话，也不随本应用锁定关闭。

## 媒体导入或播放失败

先用非重要的本地小图片验证。确保保险箱已解锁、源文件可读取、目标磁盘有空间。云盘占位文件需要先下载到本机。锁定会取消导入；确认成功后再处理原文件。格式支持依赖 Windows 解码器，部分 HEVC/MKV/AV1 文件可能需要系统扩展。

## 提交可用的错误报告

写明版本、Windows 版本、x64/ARM64、最短复现步骤、预期与实际结果。截图先遮盖地址、文件名和个人信息。优先提供合成测试文件。不要公开提交保险箱、密码、备份、原始日志或完整崩溃转储。

## 设置显示暂时只读

先关闭其他正在使用该目录的 Stealth 窗口，检查杀毒软件或同步工具是否正在占用设置文件，解除占用后再启动。保留 settings.dat 和 settings.dat.bak 两个原件。只读期间显示的可能是较早的备份，应用会阻止写入覆盖。

## 大型 HTML 收藏无法导入

单个导入文件上限为 32 MiB。在本机备份原 HTML 后，可以用文本编辑器将收藏条目分为若干 UTF-8 HTML 文件，保留每条完整的 A 标签，再依次导入。浏览器导出文件中的 ICON 图标数据不会导入，可以从副本中移除这些属性。请勿将含有私密网址的收藏上传到在线转换服务。
