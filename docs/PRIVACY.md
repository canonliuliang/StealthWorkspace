# 隐私与安全边界

Stealth 将临时网页会话与本地加密媒体管理放在一个 Windows 应用中。它不提供匿名网络，也不能防御管理员、恶意软件或内核级取证。项目尚未接受独立安全审计。

## 网页与下载

「清除 HTTP 磁盘缓存」只请求删除网络响应的磁盘缓存。网页应用保存在 CacheStorage 的离线文件、网站数据库和 Cookie 可以继续使用。「所有网站的本地存储」涵盖本次会话中各来源的离线文件和未同步数据，操作会要求确认。最近关闭列表仅在内存中保存最多 20 个网页标题、地址和标签位置；锁定、结束会话或清空临时历史会清除它。

浏览器使用独立 WebView2 临时配置目录。锁定、结束会话或退出时会释放页面并尝试删除该目录。运行时或其他程序占用文件时，应用保留目录的所有权标记，以便重试。重新启动后，应用只清理超过 24 小时、仍有本应用标记且没有活动所有者的旧目录。临时会话期间及清理完成前，网页数据可能保存在磁盘上。旧版本已遗失标记的目录仍需手动确认。

网站、搜索引擎与 WebView2/Windows 自身仍可能进行网络通信。Stealth 不隐藏 IP，不承诺消除指纹，不绕过网站的验证机制。地址栏建议使用本地收藏与本次会话历史；提交搜索才会访问配置的搜索引擎。

站点隐私面板默认修改当前标签页中当前来源的权限。离开该来源或关闭标签页会清除例外。不同协议、主机、端口和跨来源子页面各自遵循其适用规则。选择「所有网站」才会保存默认设置。开启阻止适用于新请求；关闭使用设备的标签页可以结束已开始的访问。Cookie 列表仅展示匹配当前网页地址的名称、域名和安全标记。

网页尝试自动打开新窗口时，地址栏旁会出现弹窗按钮。允许自动弹窗后，可用同一按钮随时撤销。例外仅适用于当前标签页中同一来源的网页，离开该来源或关闭标签页后失效。主动点击的登录、支付或其他新窗口链接仍按正常方式打开。

应用要求 WebView2 将崩溃转储留在本机，未配置转储上传。WebView2 默认启用平衡跟踪防护和 Microsoft Defender SmartScreen。SmartScreen 可将网址和下载相关信息发给 Microsoft 以检查危险内容。运行时和系统策略也会影响网络行为。[WebView2 数据与隐私](https://learn.microsoft.com/microsoft-edge/webview2/concepts/data-privacy) · [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)

浏览器下载的文件以明文保存在应用下载夹。结束会话会取消未完成的下载，已完成的文件会保留。可在完成提示或下载列表中选择「加密入库并粉碎原件」。应用会先保存加密文件和索引，再核对下载原件并尝试粉碎。下载列表会显示原件的处理结果。使用网页图片右键菜单或图片阅读器直接存入媒体库时，应用从内存加密图片，省去在下载夹保存明文副本的步骤。

## 媒体与密码

媒体 V2 格式采用分块 AES-256-GCM，读取时按需解密；视频无需整体解密到内存。配置和诊断日志使用当前 Windows 用户作用域的 DPAPI。本机用户身份被恶意程序控制时，这些防护不再可靠。内存、系统页面文件、休眠、备份和系统文件选择器可能留下其他痕迹。

主密码与第二空间分别派生密钥；第二空间不能隐藏其存在于磁盘配置中的事实。忘记密码没有云端恢复渠道。设置页可创建并检查加密备份，但当前备份依赖原 Windows 用户的 DPAPI，重装系统或换机后可能无法恢复。它不是跨电脑恢复方案，重要原始文件需另行备份。

## 数据位置

新安装通常位于 `%LOCALAPPDATA%\StealthWorkspace\Data`。旧安装可能继续使用 `%LOCALAPPDATA%\Microsoft\Windows\SystemDiagnostics\Data`，或程序旁的 `WorkspaceData`。只读旧目录迁移时保留原副本，删除或卸载之前检查这些位置。

从程序旁 `StealthVault_Store` 迁移旧保险箱时，会先复制并检查媒体，再提交新索引，原目录保留以便恢复。重置只删除当前保险箱；旧目录、导出文件和外部备份不会一并删除。重置会保存禁止自动导入旧目录的状态，防止旧副本在下次启动时重新出现。

- `system_catalog.dat` / `.bak`：保险箱配置与索引。
- `settings.dat` / `.bak`：设置与收藏。
- `MediaVault`：加密媒体。
- `app.log`：轮转的加密诊断日志。
- `IsolatedDownloads`：普通下载文件。

浏览器会话优先位于 `%LOCALAPPDATA%\StealthWorkspace\BrowserSessions`，失败时尝试其他可写目录。临时配置目录本身不由媒体保险箱密钥加密。

## 日志与报告

r12 开始，清理模块异常日志去除原始异常消息、注册表值和目录路径；异常诊断保留操作名、类型、错误码和方法名，不写源码位置。旧日志不会被追溯重写，其他诊断上下文仍应逐项审阅。`--dump-log` 输出明文；不要未经检查公开上传。网络诊断也可能包含网址和 Cookie，仅用于显式测试。

官网为静态页面，不加入分析 SDK、追踪像素或第三方字体；托管服务仍可能处理请求 IP 等访问数据。浏览项目、下载和提交 Issue 会受到 GitHub 自身的隐私政策约束。

## 捕获排除与清理

窗口捕获排除依赖 Windows API，无法覆盖所有截屏、录屏或远程管理路径。清理结果受权限、文件占用和系统实现影响。覆写文件不保证在 SSD、写时复制文件系统或备份中物理擦除。参见 [Windows 捕获排除 API 的限制](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)。
