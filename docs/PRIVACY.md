# 隐私与安全边界

主空间默认保留网站登录。地址栏的盾牌用于查看保护状态，以及管理网站权限、账号和离线内容。以下说明适用于当前源码构建。

## 网页与下载

| 操作 | 网站账号 | 本地浏览记录及标签 |
| --- | --- | --- |
| 关闭应用、锁定工作台或结束浏览会话 | 主空间保留网站允许跨重启使用的登录凭据 | 关闭网页，清除本次访问记录、最近关闭的标签、浏览器下载历史及网页临时文件。已保存的下载文件留在原处 |
| 在网站选择退出登录 | 网站按自己的规则使账号退出 | 可继续浏览 |
| 在盾牌的「登录」页清除本站账号和数据 | 移除本站 Cookie、离线数据与网站偏好。共享同一登录 Cookie 的相关子域名也可能退出 | 其他独立站点的账号继续使用 |
| 使用诱饵空间 | 单独使用临时的网站数据，锁定后清除 | 与主空间分开 |

网站决定登录多久有效。永久 Cookie 有到期时间，仅限本次会话的 Cookie 由浏览器处理。应用依赖 WebView2 管理登录凭据。保留 Cookie、LocalStorage 和网站数据库有助于会员、论坛和网页应用延续登录，也意味着网站可能继续识别同一用户。网站账号里的观看记录、服务器日志和离线网页内容由网站管理。清除本应用的浏览记录无法删除这些内容。

主空间使用独立于其他保险箱的 WebView2 配置。浏览器以自身的存储格式保存网站数据，网站文件不受媒体保险箱的文件加密保护。正常退出时请求内核清除历史和 HTTP 缓存。异常退出后，可能还有数据留在磁盘，下一次使用浏览器前会重试。此功能面向日常浏览记录管理，不提供匿名网络或取证级擦除保证。

盾牌的「网站文件」可以只清除网页临时文件，保留账号和离线文档。清除离线内容可能会丢失草稿或让依赖本地存储的网站重新登录。Ctrl+H 查看本次浏览记录。最近关闭列表仅在内存中保存最多 20 条。地址栏建议来自本地收藏和本次浏览记录，提交搜索时才访问搜索引擎。

主空间的收藏和文件夹由 Windows 当前用户的 DPAPI 保护。Chrome 导出的 HTML 在本机解析，保留收藏栏、嵌套文件夹及空文件夹。同一文件夹中的重复链接会合并。导出会产生包含标题和完整网址的明文 HTML。带用户名或密码的网址及非 HTTP(S) 地址会跳过。诱饵空间的收藏仅在该次解锁期间可用。

从「下载文件夹」选择「复制到加密媒体库」会保留下载原件。Windows 拒绝启动资源管理器时，仍可在应用内切换可用下载目录、查看文件和执行复制。

默认使用 WebView2 的平衡跟踪防护，它会限制已知的跨站跟踪器。网站、搜索引擎及 Windows 仍可能进行网络通信。摄像头、麦克风、位置和通知分别控制，当前网站的临时例外在离开该来源或关闭标签后失效。[微软对跟踪防护的说明](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/tracking-prevention)

网页尝试自动打开新窗口时，地址栏旁会出现弹窗按钮。允许自动弹窗后，可用同一按钮随时撤销。例外仅适用于当前标签页中同一来源的网页，离开该来源或关闭标签页后失效。主动点击的登录、支付或其他新窗口链接仍按正常方式打开。

应用要求 WebView2 将崩溃转储留在本机，未配置转储上传。WebView2 默认启用平衡跟踪防护和 Microsoft Defender SmartScreen。SmartScreen 可将网址和下载相关信息发给 Microsoft 以检查危险内容。运行时和系统策略也会影响网络行为。[WebView2 数据与隐私](https://learn.microsoft.com/microsoft-edge/webview2/concepts/data-privacy) · [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)

浏览器下载的文件以明文保存在应用下载夹。结束会话会取消未完成的下载，已完成的文件会保留。可在完成提示或下载列表中选择「加密入库并粉碎原件」。应用会先保存加密文件和索引，再核对下载原件并尝试粉碎。下载列表会显示原件的处理结果。使用网页图片右键菜单或图片阅读器直接存入媒体库时，应用从内存加密图片，省去在下载夹保存明文副本的步骤。

「更多操作 → 复制净化链接」只在主动选择时读取当前网页地址。应用移除清单中已知的跟踪参数，原样保留其余字段。检测到常见凭据、敏感路径、签名或令牌字段时跳过复制。自定义字段仍可能包含敏感信息，分享前可检查结果。应用要求 Windows 对此次复制禁用剪贴板历史和云漫游，同一桌面的程序仍可读取当前剪贴板。Windows 文件选择器可能按系统设置记录最近访问的位置。

## 媒体与密码

媒体 V2 格式采用分块 AES-256-GCM，读取时按需解密；视频无需整体解密到内存。配置和诊断日志使用当前 Windows 用户作用域的 DPAPI。本机用户身份被恶意程序控制时，这些防护不再可靠。内存、系统页面文件、休眠、备份和系统文件选择器可能留下其他痕迹。

主密码与第二空间分别派生密钥；第二空间不能隐藏其存在于磁盘配置中的事实。忘记密码没有云端恢复渠道。设置页可创建并检查加密备份，但当前备份依赖原 Windows 用户的 DPAPI，重装系统或换机后可能无法恢复。它不是跨电脑恢复方案，重要原始文件需另行备份。

## 数据位置

新安装通常位于 `%LOCALAPPDATA%\StealthWorkspace\Data`。旧安装可能继续使用 `%LOCALAPPDATA%\Microsoft\Windows\SystemDiagnostics\Data`，或程序旁的 `WorkspaceData`。只读旧目录迁移时保留原副本，删除或卸载之前检查这些位置。

从程序旁 `StealthVault_Store` 迁移旧保险箱时，会先复制并检查媒体，再提交新索引，原目录保留以便恢复。重置只删除当前保险箱；旧目录、导出文件和外部备份不会一并删除。重置会保存禁止自动导入旧目录的状态，防止旧副本在下次启动时重新出现。

- `system_catalog.dat` / `.bak`：保险箱配置与索引。
- `settings.dat` / `.bak`：设置与收藏。
- `MediaVault`：加密媒体。
- `app.log`：轮转的加密诊断日志。
- `IsolatedDownloads`：普通下载文件。
- 主空间的网站账户位于当前 Windows 用户的 `AppData\LocalLow\StealthWorkspace\BrowserAccounts`。它与其他保险箱、其他浏览器及临时空间隔离。保险箱备份不包含这些浏览器账户；导出或恢复备份后可能需要重新登录。

主空间的账号配置保存在本机应用专用目录中。诱饵空间使用带所有权标识的临时配置。加密媒体备份和发布包不包含网站账号配置。

新安装默认关闭启动时检查 Windows 缩略图缓存，已有用户保存的选择继续生效。如果保险箱的主索引和备份索引都已损坏，应用无法确认旧网站文件的归属时会保留这些文件。新建保险箱使用新的身份，不能接管旧账号。

## 日志与报告

r12 开始，清理模块异常日志去除原始异常消息、注册表值和目录路径；异常诊断保留操作名、类型、错误码和方法名，不写源码位置。旧日志不会被追溯重写，其他诊断上下文仍应逐项审阅。`--dump-log` 输出明文；不要未经检查公开上传。网络诊断也可能包含网址和 Cookie，仅用于显式测试。

官网为静态页面，不加入分析 SDK、追踪像素或第三方字体；托管服务仍可能处理请求 IP 等访问数据。浏览项目、下载和提交 Issue 会受到 GitHub 自身的隐私政策约束。

## 捕获排除与清理

可自行启用「跟随 Windows 锁定工作台」。在 Windows 送达锁屏、控制台或远程会话断开、睡眠通知时，工作台执行平时的锁定流程。未提交表单可能丢失；解锁 Windows 后仍需解锁工作台。首次打开应用显示锁页时会保留当前剪贴板。新安装默认保留整机 DNS 缓存，已有用户保存的退出清理偏好继续生效。

窗口捕获排除依赖 Windows API，无法覆盖所有截屏、录屏或远程管理路径。清理结果受权限、文件占用和系统实现影响。覆写文件不保证在 SSD、写时复制文件系统或备份中物理擦除。参见 [Windows 捕获排除 API 的限制](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)。
