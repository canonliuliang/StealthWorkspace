# Brand marks

- `assets/github-mark.svg` is the unmodified `GitHub Logos/SVG/GitHub_Invertocat_Black.svg` from [GitHub's official logo download](https://brand.github.com/GitHub_Logos.zip), retrieved 2026-11-14. It appears beside links to this project's GitHub repository. [GitHub brand guidance](https://brand.github.com/foundations/logo).
- The inline `windows-mark` is a four-pane vector used to identify Windows downloads. Windows and Microsoft marks belong to Microsoft.

Both marks are secondary to the Stealth brand and decorative beside visible text. No affiliation or endorsement is implied. No remote icon scripts, fonts, or CDN requests are required.
